# Anotações das aulas

Use esta pasta para registrar explicações do professor, dúvidas, exemplos feitos em sala e o que precisa ser revisado. A documentação geral fica em `docs/`; aqui ficam as observações pessoais.

## Modelo para uma nova aula

Crie um arquivo como `aula-2026-10-15.md` e use o roteiro abaixo:

```markdown
# Aula — AAAA-MM-DD

## Assunto
Qual foi o tema principal?

## O que entendi
Explique com suas palavras.

## Exemplo feito em aula
Cole ou reescreva o exemplo, preservando o contexto.

## Dúvidas
- [ ] Dúvida que ainda preciso resolver

## Exercício para refazer
Registre o enunciado ou a referência.

## Revisão
- [ ] Consigo explicar sem consultar o material
- [ ] Refiz o exemplo sozinho
- [ ] Resolvi um exercício semelhante
```

## Como manter as anotações úteis

- Registre a data e o assunto.
- Diferencie o que foi explicado em aula de pesquisas complementares.
- Se uma dúvida for resolvida, acrescente a explicação em vez de apagar o contexto.
- Não cole material de terceiros sem verificar se você tem autorização para redistribuí-lo.
