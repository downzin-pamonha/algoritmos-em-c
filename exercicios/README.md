# Exercícios de fixação

Os exercícios estão organizados por dificuldade. Tente resolver cada enunciado antes de consultar `solucoes/`. Crie um arquivo `.c` para cada solução e compile-o localmente.

## Como praticar

1. Leia o enunciado e identifique entrada, processamento e saída.
2. Escreva os passos em português antes do código.
3. Implemente uma solução simples.
4. Teste valores normais, limites e entradas inválidas quando aplicável.
5. Só então compare com uma solução comentada.

- [Iniciantes](iniciantes/README.md)
- [Desafios](desafios/README.md)
- [Soluções comentadas](solucoes/README.md)

As soluções são referências possíveis, não a única forma correta de resolver todos os problemas.
