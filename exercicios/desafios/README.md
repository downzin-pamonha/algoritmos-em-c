# Desafios

Estes desafios combinam os assuntos iniciais documentados. Não exigem funções, vetores, matrizes ou ponteiros.

## 1. Calculadora de duas operações
Leia dois números e uma opção de menu. Use `switch` para selecionar soma, subtração ou multiplicação. Trate opção inválida.

**Critérios:** entrada validada; cada opção produz o cálculo correto.

## 2. Contagem seletiva
Leia um inteiro positivo `N`. Conte de 1 até `N`, exibindo somente os números pares.

**Dica:** use um laço e o operador `%`.

## 3. Estatística de cinco números
Leia cinco inteiros com um laço. Ao final, exiba a soma e quantos números são positivos.

**Dica:** inicialize os acumuladores antes do laço.

## 4. Tentativas de senha numérica
Defina um número de acesso fixo no programa. Peça uma tentativa e continue solicitando enquanto estiver incorreta, encerrando quando acertar.

**Dica:** use `while` e deixe explícita a condição de parada. Para este exercício, não use dados reais nem senhas pessoais.

## 5. Conversor de temperatura
Leia uma temperatura em Celsius e converta para Fahrenheit usando `F = C * 9 / 5 + 32`. Exiba duas casas decimais.

**Critério:** teste `0 °C`, cujo resultado deve ser `32 °F`.

## Antes de considerar concluído

- [ ] O programa compila sem avisos relevantes.
- [ ] Testei entradas normais e limites.
- [ ] Tratei opções ou entradas inválidas quando aplicável.
- [ ] Consigo explicar o algoritmo sem olhar a solução.
