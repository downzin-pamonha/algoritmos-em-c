# Exemplos: funções em C

Exemplos introdutórios para praticar declaração, chamada, parâmetros e retorno de funções.

- [`somar-dois-numeros.c`](somar-dois-numeros.c): recebe dois inteiros na chamada da função e retorna a soma.
- [Documentação sobre funções](../../docs/12-funcoes.md): explicação completa, erros comuns e exercícios.

Compile a partir da raiz do repositório:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic exemplos/funcoes/somar-dois-numeros.c -o somar-dois-numeros
```
